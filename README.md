# Himani Parmar — Portfolio

A responsive dark-plum and pink personal portfolio built with React, Vite, Framer Motion, and React Three Fiber.

## Highlights
- Custom animated 3D Torus Knot hero, floating labels, and scroll-linked motion.
- Smooth section reveals, progress indicator, animated marquee, and responsive navigation.
- Project gallery with category filters and custom CSS visuals.
- About, research internship, education, skills, certifications, and contact sections.
- Responsive styles and reduced-motion support.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
Import this repository into Vercel or Netlify. Use `npm run build` as the build command and `dist` as the output directory.
